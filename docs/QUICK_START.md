# 快速开始

## 在 IDEA 里运行

1. 打开项目目录
2. 等待 Maven 加载完成
3. 展开 `src/main/java/com/example/javabasic`
4. 打开任意 `*Demo.java`
5. 点击 `main` 方法左侧绿色按钮

## 推荐第一天学习任务

按顺序运行：

1. `HelloWorldDemo`
2. `CommentsAndPrintDemo`
3. `VariableDemo`
4. `DataTypeDemo`
5. `OperatorDemo`
6. `ControlFlowDemo`
7. `StringCommonFunctionsDemo`
8. `ArrayAlgorithmDemo`
9. `MethodBasicDemo`
10. `DebugDemo`

第一天目标不是背 API，而是能做到：

- 看懂类、方法、大括号
- 能定义变量并打印
- 能写 if 和 for
- 能看懂数组下标
- 会打断点并观察变量变化

## 每个 demo 怎么学

建议使用四步：

1. 先直接运行，看输出
2. 修改一个数字或字符串，再运行
3. 给关键行打断点，单步执行
4. 自己新建一个类似的类，照着写一遍

## 不要一开始纠结的东西

刚入门时可以先不纠结：

- JVM 底层原理
- 多线程
- 复杂设计模式
- Spring 源码
- 各种框架配置

先把变量、流程控制、数组、方法、类和对象练熟。
